# Shared

## TLDR

What every agent in this brain reads and writes: decisions, learnings, standing memories and the day-by-day sessions of work that affects everyone. An agent's own notes live in `../agents/<name>/`; move one here with `brain_share` when the others should know it.

## Records

The things work is about, one file each, linked with `[[folder/id]]` (e.g. `[[people/sam]]`, which Obsidian resolves too): `projects/`, `people/`, `teams/`, `customers/`, `meetings/`, `documents/`. Use `record_save` / `record_get`. `health.md` is the latest `brainium lint` report.
