# Personal brain

## TLDR

Your **personal brain**: memory that follows *you* across projects, apps and accounts. Project knowledge stays in each repo's `docs/brainium/`; this repo holds what belongs to you — preferences, agent cards, cross-project learnings and sessions that happened outside any repo. It lives in git, not in Cursor, Anthropic or xAI, so it survives switching accounts.

## Folder map

```
agents/        # Agent cards — recreate any agent on any account
sessions/      # Daily roll-ups of work outside a project brain
memories/      # Preferences, people, standing context
learnings/     # Cross-project knowledge
decisions/     # Personal decisions and their reasons
questions/     # Researched Q&A worth keeping
improvements/  # Ideas and follow-ups
```

## Where things go

| It's about… | File it in |
|---|---|
| One repo's code, tickets, incidents | that repo's `docs/brainium/` |
| You, your preferences, how you like to work | `memories/` here |
| An agent you'll want to recreate elsewhere | `agents/` here |
| Something learned that applies across projects | `learnings/` here |
| Work with no repo (research, writing, chats) | `sessions/` here |

**No secrets.** Never store keys, tokens, passwords or login details — agent cards name connectors, never their credentials.
