# Sessions

## TLDR

One file per **calendar day**: `YYYY-MM-DD.md` — not one file per chat thread.

- After midnight, append **today’s** file even if the conversation continues. `### 00:02` on a new day goes on **that** day’s file, not yesterday’s.
- Confirm the date before every append; add an index row here when you start a new day.
- Wrong day? Move sections to the correct `YYYY-MM-DD.md` in the same fix.

Link out to failures/learnings instead of duplicating long prose.
