# Contributing

Thanks for helping improve Brainium.

## Scope

- Keep **cursor/rules** and **cursor/skills** project-agnostic (no product names, no single-company git policy unless optional).
- Put product-specific incident patterns in **extensions/** as `.mdc.fragment` files.
- Templates use `YYYY-MM-DD` slugs and TLDR sections.

## PR checklist

- [ ] README / INSTALL still accurate
- [ ] `scripts/install.sh` tested on a fresh directory
- [ ] No secrets or private URLs in examples
